AgentRouter contributes five separate execution units. ABR DNS origins retain
the `abrdns-welfare` logical grouping. Three LinuxDO-authenticated welfare
origins share the metadata group `linuxdo-shared`; this does not share browser
state or perform a login in alpha.

The imported run reported `executionComplete=true` but
`businessComplete=false`, because one site required attention and one was
deferred. The legacy health file reported healthy but was older than the
26-hour freshness budget, so V2 marks health as stale. This is intentional:
health freshness is evaluated independently of the legacy boolean.

No credentials, cookies, tokens, account IDs, profile paths, screenshots, or
notification payloads are present in the snapshot.
